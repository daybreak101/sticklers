You cannot use process.env directly in app runtime
You must use:

1) in app.config.js / app.json

export default {
  expo: {
    extra: {
      FIREBASE_API_KEY: process.env.FIREBASE_API_KEY,
    },
  },
};

then access it in app
import Constants from "expo-constants";

const apiKey = Constants.expoConfig?.extra?.FIREBASE_API_KEY;

2) use babel-plugin-inline-dotenv
or expo-env
